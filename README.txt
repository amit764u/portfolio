DR. AMIT KUMAR SAXENA — PORTFOLIO WEBSITE

Files:
- index.html : website content and sections
- style.css  : responsive design and styling
- script.js  : mobile navigation, current year, contact-form email draft
- README.txt : setup instructions

HOW TO VIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to view the site in your browser.

BEFORE PUBLISHING
- Replace “Add your preferred professional email” in index.html.
- Replace “Add your LinkedIn profile URL” with your real LinkedIn link.
- In script.js, replace YOUR-PROFESSIONAL-EMAIL@example.com with your verified email.
- Add a professional headshot if desired.
- Verify career dates, institutional wording, project status and all claims against official records.
- The functional-milk section is intentionally described as a research concept, not a proven cancer-preventive product.
- This is a front-end website; the contact form opens an email draft and does not store or send data to a server.

Built with plain HTML, CSS and JavaScript.
